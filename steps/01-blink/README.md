# 01. LED 깜빡이기 (Blink)

ESP32의 GPIO 출력으로 LED를 0.5초 간격으로 켜고 끄는 첫 번째 예제

- **시뮬레이션:** [Wokwi에서 실행하기](https://wokwi.com/projects/481509599739070465)
- **언어:** C++ (Arduino framework)

---

## 회로

| 부품 | 연결 |
|---|---|
| 저항 220Ω | GPIO16 ↔ LED 애노드(+) |
| LED (빨강) | 애노드(+) ↔ 저항 / 캐소드(−) ↔ GND |

```
GPIO16 (3.3V) ─[220Ω]─ LED(+ → −) ─ GND (0V)
```

---

## 코드

```cpp
const int LED_PIN = 16;          // LED가 연결된 핀 번호 (상수)

void setup() {                   // 부팅 시 1회 실행
  Serial.begin(115200);          // PC와 시리얼 통신 시작 (115200bps)
  pinMode(LED_PIN, OUTPUT);      // 16번 핀을 출력 모드로 설정
}

void loop() {                    // 전원이 꺼질 때까지 무한 반복
  digitalWrite(LED_PIN, HIGH);   // 3.3V 출력 → LED 켜짐
  Serial.println("ON");
  delay(500);                    // 0.5초 대기
  digitalWrite(LED_PIN, LOW);    // 0V 출력 → LED 꺼짐
  Serial.println("OFF");
  delay(500);
}
```

**동작 흐름:** `setup()` 1회 → `loop()` 반복 (켜기 → 0.5초 → 끄기 → 0.5초)

> `delay()` 동안 ESP32는 다른 작업을 하지 못한다. 센서·버튼을 함께 쓰는 단계에서는 `millis()` 기반 논블로킹 방식으로 바꿀 예정.

## 회로 이론 정리

### 1. 저항을 넣는 이유 — 전류 제한
- LED는 켜지는 전압(빨강 약 1.8~2V)을 넘으면 전류가 급격히 증가하고, **스스로 전류를 제한하지 못한다.**
- 저항 없이 연결하면 과전류로 **LED 손상** 및 **ESP32 핀 손상**(권장 약 20mA, 최대 약 40mA 초과) 위험이 있다.
- 저항은 **회로 전체에 흐르는 전류의 양**을 정해 준다.

### 2. 220Ω을 고른 이유 — 옴의 법칙
```
저항 전압 = 공급 전압 − LED 전압 = 3.3V − 2.0V = 1.3V
전류     = 1.3V ÷ 220Ω ≈ 6mA
```
- 6mA는 충분히 밝으면서 LED와 핀 모두 안전한 범위
- 색띠: 빨강(2) 빨강(2) 갈색(×10) → **220Ω**
- 파랑·초록 LED는 켜지는 전압이 약 3V로 높아 3.3V에서는 같은 저항이라도 더 어둡다

### 3. LED 방향 — 다이오드
LED는 전류가 **애노드(+) → 캐소드(−)** 한 방향으로만 흐른다. 반대로 연결하면 켜지지 않는다.

| 구분 | 애노드(+) | 캐소드(−) |
|---|---|---|
| Wokwi | 꺾인 다리 | 곧은 다리 |
| 실물 | 긴 다리 | 짧은 다리, 테두리가 평평한 쪽 |
| 연결 | GPIO 쪽 | GND 쪽 |

### 4. GND에 연결하는 이유 — 닫힌 회로
- 전류는 전압이 높은 곳에서 낮은 곳으로, **닫힌 회로**가 있을 때만 흐른다.
- `HIGH`: 핀 3.3V ↔ GND 0V → 전압 차 발생 → 전류 흐름 → **켜짐**
- `LOW`: 핀 0V ↔ GND 0V → 전압 차 없음 → **꺼짐**

### 5. 저항 위치는 LED 앞이든 뒤든 상관없다
직렬 회로는 길이 하나뿐이라 **모든 지점에 같은 전류**가 흐른다. 전류는 LED에서 소모되어 줄어드는 것이 아니다.

| 연결 순서 | LED 양단 전압 | 저항 양단 전압 | 전류 |
|---|---|---|---|
| 핀 → 저항 → LED → GND | 2.0V | 1.3V | 약 6mA |
| 핀 → LED → 저항 → GND | 2.0V | 1.3V | 약 6mA |

LED가 받는 조건은 **두 다리 사이의 전압 차**와 **흐르는 전류**로 정해지므로 두 경우가 동일하다.
단, LED 방향(+는 핀 쪽, −는 GND 쪽)은 유지해야 한다.

### 6. LED 밝기와 수명은 전류가 결정한다
- LED 전압과 전류는 비례하지 않는다. 켜지는 전압 근처에서 **전압이 조금만 올라도 전류가 크게 증가**한다.
- 그래서 LED는 전압이 아니라 **저항으로 전류를 정해서** 사용한다. LED 전압은 약 2V 근처에 자리 잡고, 나머지 전압은 저항이 가져간다.
- 정격 범위 안에서 **밝기는 전류에 거의 비례**하고, 전류가 클수록 발열이 커져 **수명이 줄어든다.**

| 저항 | 전류(약) | 밝기 | 수명 |
|---|---|---|---|
| 1kΩ | 1.3mA | 어둡지만 보임 | 매우 김 |
| **220Ω** | **6mA** | **충분히 밝음** | **김** |
| 100Ω | 13mA | 더 밝음 | 김 |
| 없음 | 과전류 | 순간 매우 밝음 | 손상 |

*수치는 LED 제품마다 다른 대략적인 값*

## 배운 점
- Arduino 코드는 `setup()`(1회)과 `loop()`(반복) 구조로 동작한다.
- LED 회로에서 저항은 전압을 미리 깎는 것이 아니라 **회로 전체의 전류를 제한**한다.
- 옴의 법칙으로 필요한 저항값을 직접 계산할 수 있다.
