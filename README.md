# ESP32 Smart Room Monitor

ESP32로 실내 온습도·조도·움직임을 측정하고, 웹으로 확인·제어하는 IoT 프로젝트

## 목표 기능
- [ ] 온습도·조도 측정 및 OLED 표시
- [ ] Wi-Fi 웹 대시보드
- [ ] 릴레이·LED 원격 제어
- [ ] 움직임 감지 경보

## 진행 기록
| 단계 | 내용 | 시뮬레이션 |
|---|---|---|
| 01 | LED 깜빡이기 | [Wokwi](https://wokwi.com/projects/481509599739070465) |
| 02 | 버튼 입력 · 토글 · 디바운싱 | [Wokwi](https://wokwi.com/projects/481571444371519489) |

## 개발 환경
- 보드: ESP32 DevKit (ESP-WROOM-32)
- 언어: C++ (Arduino framework)
- 시뮬레이터: Wokwi
